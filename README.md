# AI-Powered E-Commerce Customer and Sales Intelligence

## Project Overview
This project uses Exploratory Data Analysis (EDA) to explore e-commerce customer and sales data, identify patterns, and derive useful business insights.

## Dataset
- Approximately 1,000,123 rows and 62 columns.
- The original CSV dataset is approximately 391 MB and is not included in this repository due to its size.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Data understanding and exploration
2. Data quality checks and cleaning
3. Exploratory Data Analysis
4. Data visualization
5. Interpretation of business patterns

## Analysis Areas
- Order status distribution
- Traffic source analysis
- Delivery time patterns
- Sales and profitability fields
- Customer-related data

## Key Learning Outcomes
- Working with a large dataset
- Performing data exploration and analysis
- Creating visualizations
- Identifying patterns and communicating insights

## How to Run
1. Download the notebook from this repository.
2. Obtain the dataset separately, ensuring you have permission to use it.
3. Install the required Python libraries.
4. Update the dataset file path in the notebook if necessary.
5. Run the notebook in Jupyter Notebook.

**Note:** This repository contains the analysis notebook, not the original CSV dataset.
